Developer Reference

Plugin Architecture & Core Bindings

Modular, typed architecture conforming to Cordis lifecycle patterns and DeepSeek Harness protocols.

Cordis Lifecycle

apply() Service Injection & Tool Registry

The plugin entrypoint (lib/index.js) cleanly injects into tools and webServer services, registering model tools and REST routes with automatic disposal on context unmount.

// Cordis Plugin Lifecycle Implementation (lib/index.js) import { defineTool } from '@deepseek-ai/dsh-tools'; export const name = 'dsh-agentic-swarm'; export const inject = ['tools', 'webServer']; export function apply(ctx, config = {}) { // 1. Reactive Cordis Service Injection ctx.inject(['tools'], (sctx) => { sctx.effect(() => { const dispose = sctx.tools.register( defineTool({ name: 'swarm_dispatch', description: 'Launch autonomous multi-agent swarm mission', parameters: { goal: { type: 'string', description: 'Mission objective' }, maxSteps: { type: 'number', default: 30 } }, async execute(args) { return await coordinator.runAutonomousMission(args.goal); } }) ); return dispose; // Quiescent disposal on unmount }); }); }
Decentralized Memory

Message Bus & Blackboard

High-speed event-driven message bus. Subagents exchange structured tasks, peer queries, tool execution requests, and audit logs.

• bus.sendDirect('coder', 'architect')
• bus.broadcast('coordinator', 'Phase 2')
• bus.setBlackboard('schema', spec)
• bus.postToolEvent('mcp-specialist', tool)

Implements strict trust boundaries separating operator control flow from untrusted tool observation.

Autonomous Execution

Zero-Intervention MCP & Skills

Discovers tools across connected MCP servers (ClickUp, Browser, Playwright, Memory, Filesystem) and local skills. Subagents select and invoke tools without waiting for user prompts or approval.

Adversarial Review

Automated Self-Healing Loops

The Critic Agent acts as an adversarial auditor. If syntax, test coverage, or security requirements fall short, the Critic issues specific remediation instructions, triggering an automated self-healing cycle until verified.

Technical Setup

Installation & Cordis Patch

Add the plugin to your DSH web profile configuration.

1. Cordis Configuration Patch

Add the following block to your ~/.dsh/profiles/web/cordis.patch.yml:

- insert: - id: agentic-swarm name: "dsh-agentic-swarm" config: telegram: enabled: true botToken: "YOUR_TELEGRAM_BOT_TOKEN" allowedUsers: ["YOUR_TELEGRAM_USER_ID"] pollIntervalMs: 1500 autonomous: maxSteps: 30 autoExecuteMcp: true autoExecuteSkills: true criticReview: true selfHealing: true agents: defaultCoordinator: "lead-coordinator"

2. Model-Facing DSH Tools

Tool Name Arguments Description
swarm_dispatch goal, maxSteps Launches an autonomous multi-agent swarm mission with step breakdown, tool execution, and verification.
swarm_status none Snapshot of active mission, queued tasks, registered agents, metrics, and message bus history.
swarm_broadcast message Broadcasts text guidance to all agents on the swarm message bus.
swarm_message to, content Sends a direct peer-to-peer message to a specific agent in the swarm.
swarm_telegram_notify chatId, message Sends a notification or report directly to the configured Telegram chat.
swarm_tool_exec toolName, args Allows autonomous subagents to execute registered MCP or system tools without human prompt.
