Key Pillars

Engineered for Radical Autonomy

Every layer of the swarm is built on Cordis lifecycle principles and DeepSeek Harness protocols.

Autonomous Execution

Zero-Intervention MCP & Skill Execution

Subagents autonomously discover and execute external Model Context Protocol (MCP) servers and DSH skills without prompting the user. From Playwright browser automation and ClickUp tasks to file operations and web search, tools are resolved and dispatched on-the-fly.

// Autonomous subagent invoking MCP tool dynamically const res = await mcpBridge.executeTool('clickup_create_task', { name: 'Implement neural backtesting engine', list_id: '9012019' });
Decentralized Memory

Swarm Blackboard

Shared high-speed key-value store and message bus. Subagents exchange schemas, intermediate code, and telemetry seamlessly.

• bus.sendDirect('coder', 'architect')
• bus.broadcast('coordinator', 'Phase 2')
• bus.setBlackboard('api_schema', spec)
Adversarial Verification

Automated Self-Healing Loop

The Critic Agent acts as an adversarial auditor. If code syntax, test coverage, or security requirements fall short, the Critic rejects the deliverable and issues specific remediation tickets, re-triggering subagent refinement automatically.

Native DSH Suite

Built-in DSH Tools & REST API

Directly registers swarm_dispatch, swarm_status, swarm_broadcast, and swarm_tool_exec into the model's toolkit, while mounting real-time monitoring endpoints on http://127.0.0.1:3080/api/dsh-swarm/*.

Execution Workflow

The Autonomous Lifecycle

How goals transition into verified deliverables without human intervention.

STEP 01

Goal Planning

Lead Coordinator and Architect analyze the prompt, structure subtasks, and post the strategic roadmap to the Blackboard.

STEP 02

Specialist Collaboration

Subagents work in parallel or dependency chains, sending direct peer messages to align on contracts and schemas.

STEP 03

MCP & Skill Execution

Tools on connected MCP servers (ClickUp, Browser, Playwright, Memory) and local skills are invoked automatically.

STEP 04

Adversarial Verification

The Critic Agent audits outputs. Upon discovering flaws, it triggers an automated self-healing loop until validated.

Technical Reference

Installation & Configuration

Step-by-step setup for DeepSeek Harness Web Profile.

1. Cordis Configuration Patch

Add the following block to your ~/.dsh/profiles/web/cordis.patch.yml:

- insert: - id: agentic-swarm name: "dsh-agentic-swarm" config: telegram: enabled: true botToken: "YOUR_TELEGRAM_BOT_TOKEN" allowedUsers: ["YOUR_TELEGRAM_USER_ID"] pollIntervalMs: 1500 autonomous: maxSteps: 30 autoExecuteMcp: true autoExecuteSkills: true criticReview: true selfHealing: true agents: defaultCoordinator: "lead-coordinator"

2. Registered Model-Facing DSH Tools

Tool Name Arguments Description
swarm_dispatch goal, maxSteps Launches an autonomous multi-agent swarm mission with full step breakdown, MCP execution, and review.
swarm_status none Snapshot of active mission, queued tasks, registered agents, metrics, and message bus history.
swarm_broadcast message Broadcasts text guidance to all agents on the swarm message bus.
swarm_message to, content Sends a direct peer-to-peer message to a specific agent in the swarm.
swarm_telegram_notify chatId, message Sends a notification or report directly to the configured Telegram chat.
swarm_tool_exec toolName, args Allows autonomous subagents to execute registered MCP or system tools without human prompt.
